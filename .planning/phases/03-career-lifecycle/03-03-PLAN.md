<objective>
Transcribe all 12 career data files from the Core Rulebook PDF into JSON format and create the data index with Zod validation.

Purpose: This is the single largest data transcription task in the project (~1,200 entries). Each career needs qualification targets, 3 assignments with survival/advancement targets and specialist skills, rank tables with bonus skills, 5 skill training tables, 11 event entries, 6 mishap entries, and mustering out tables. Per D-08, these are JSON files validated by Zod schemas.
Output: 12 career JSON files, index.ts with validated imports, structural tests.
</objective>

<task type="auto">
  <name>Task 1: Transcribe all 12 career JSON files from Core Rulebook</name>
  <files>src/data/careers/agent.json, src/data/careers/army.json, src/data/careers/citizen.json, src/data/careers/drifter.json, src/data/careers/entertainer.json, src/data/careers/marine.json, src/data/careers/merchant.json, src/data/careers/navy.json, src/data/careers/noble.json, src/data/careers/rogue.json, src/data/careers/scholar.json, src/data/careers/scout.json</files>
  <read_first>"MgT 2E - Core Rulebook (Printer Friendly).pdf", src/types/careers.ts, src/schemas/career.ts</read_first>
  <action>
    Read the Core Rulebook PDF career sections (approximately pages 20-55 in the character creation chapter). For EACH of the 12 careers, create a JSON file in src/data/careers/ with:

    1. **name**: Career name (capitalized)
    2. **description**: Brief career description from rulebook
    3. **qualification**: { characteristic: "XXX", target: N } or null for Drifter (auto-entry)
    4. **isMilitary**: true for Army, Marines, Navy; false for others
    5. **commission**: { characteristic: "SOC", target: N } for military careers; null for civilians
    6. **basicTrainingException**: true for Citizen and Drifter ONLY; false for all others
    7. **assignments** (array of 3): Each with:
       - name, description
       - survival: { characteristic, target }
       - advancement: { characteristic, target }
       - specialistSkills: array of exactly 6 SkillEntry values
    8. **ranks**: { enlisted: array of RankEntry (7 entries, levels 0-6), officer: array of RankEntry (7 entries, levels 0-6) for military only }
       - Each rank: { level, title, bonusSkill (or null), bonusSkillLevel (0 or 1, optional) }
    9. **skillTables**: { personalDevelopment: 6 entries, serviceSkills: 6 entries, advancedEducation: 6 entries, officer: 6 entries (military only) }
    10. **events**: 11 entries for 2D table (rolls 2-12). Each with rollValue, description (narrative text), effectDescription (mechanical text), effects array, hasChoice boolean
    11. **mishaps**: 6 entries for 1D table (rolls 1-6). Same structure as events.
    12. **musteringOut**: { cash: [7 numbers], benefits: [7 strings] }

    The 12 careers to transcribe:
    - Agent (Law Enforcement, Intelligence, Corporate)
    - Army (Support, Infantry, Cavalry)
    - Citizen (Corporate, Worker, Colonist)
    - Drifter (Barbarian, Wanderer, Scavenger)
    - Entertainer (Artist, Journalist, Performer)
    - Marine (Support, Star Marine, Ground Assault)
    - Merchant (Merchant Marine, Free Trader, Broker)
    - Navy (Line/Crew, Engineer/Gunner, Flight)
    - Noble (Administrator, Diplomat, Dilettante)
    - Rogue (Thief, Enforcer, Pirate)
    - Scholar (Field Researcher, Scientist, Physician)
    - Scout (Courier, Survey, Exploration)

    CRITICAL: Read every value directly from the PDF. Do not guess or approximate. Pay special attention to:
    - Correct characteristic abbreviations (STR, DEX, END, INT, EDU, SOC)
    - Exact target numbers for qualification, survival, advancement, commission
    - Exact skill names matching existing skill naming conventions
    - Correct rank titles at each level
    - Whether bonusSkill is null or has a specific skill at a specific level
  </action>
  <verify>
    <automated>node -e "const fs=require('fs'); const careers=['agent','army','citizen','drifter','entertainer','marine','merchant','navy','noble','rogue','scholar','scout']; careers.forEach(c => { const d=JSON.parse(fs.readFileSync('src/data/careers/'+c+'.json','utf8')); console.log(c+': assignments='+d.assignments.length+' events='+d.events.length+' mishaps='+d.mishaps.length); })"</automated>
  </verify>
  <acceptance_criteria>

    - Each file has exactly 3 assignments, 11 events, 6 mishaps
    - Each file has musteringOut with cash array of 7 and benefits array of 7
    - Citizen and Drifter JSON have "basicTrainingException": true
    - Army, Marine, Navy JSON have "isMilitary": true and non-null commission
    - Drifter JSON has "qualification": null
  </acceptance_criteria>
