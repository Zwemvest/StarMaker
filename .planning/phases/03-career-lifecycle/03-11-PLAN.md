### New contract (same signature, different behavior for subsequent careers):
```typescript
export function getBasicTrainingSkills(
  career: CareerData,
  isFirstCareer: boolean,
  assignmentIndex: number,
): SkillEntry[] {
  // First career or Citizen/Drifter exception: return the full pool
  // Subsequent careers: ALSO return the full pool — the UI picks one instead of granting all
  // The DIFFERENCE between first and subsequent careers lives in BasicTrainingCard,
  // not here. This function returns candidates; the caller decides whether to grant
  // all of them or to present a pick-one UI.
  if (career.basicTrainingException) {
    return career.assignments[assignmentIndex].specialistSkills;
  }
  return career.skillTables.serviceSkills;
}
```

Note: the signature preserves `isFirstCareer` as a parameter. It's now UNUSED in the engine (keep the parameter for API stability and because it's exported with this signature). Add an underscore prefix or a `void isFirstCareer;` line and a comment explaining why it's retained.
