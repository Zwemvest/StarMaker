<objective>
Close UAT gaps 1 and 2: add a decline path to confirmation gates (Characteristics review, Background Skills review) and let users directly unassign items from slots by clicking an × button.

Purpose: The current review gates are one-way doors at both the XState and UI layers, and assigned slots have no remove affordance — the state-layer `unassignSlot` is exported but never consumed. This plan wires the existing state-layer capability into the UI and adds an EDIT transition so users can back out of review without losing their assignments.

Output: EDIT transitions on two review states, optional onRemove prop on DropSlot, × buttons on StatSlot/SkillSlot, decline buttons on both review screens (that do NOT commit to the store), and regression tests for the unassign + decline paths.
</objective>
