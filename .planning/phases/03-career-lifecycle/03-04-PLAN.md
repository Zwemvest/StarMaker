
    New CreationContext fields:
    ```typescript
    currentCareer: CareerName | null;
    currentAssignment: string | null;
    careerTermCount: number;           // Terms in CURRENT career
    totalTermsServed: number;          // All careers combined
    isCommissioned: boolean;
    justCommissioned: boolean;         // Prevents advancement same term (CRER-12)
    forcedToLeave: boolean;
    forcedToStay: boolean;
    ```

    Career sub-states (per research Pattern 3):
    ```
    career (compound state)
      initial: choosingCareer
      states:
        choosingCareer          -> CHOOSE_CAREER -> choosingAssignment
        choosingAssignment      -> CHOOSE_ASSIGNMENT -> qualificationRoll
        qualificationRoll       -> QUALIFICATION_SUCCESS -> basicTraining
                                -> QUALIFICATION_FAILURE -> qualificationFailed
        qualificationFailed     -> CHOOSE_DRAFT -> basicTraining (with draft assignment)
                                -> CHOOSE_DRIFTER -> basicTraining (as drifter)
        basicTraining           -> BASIC_TRAINING_COMPLETE -> termLoop
        termLoop (compound)
          initial: survivalRoll
          states:
            survivalRoll        -> SURVIVAL_SUCCESS -> event
                                -> SURVIVAL_FAILURE -> mishap
            mishap               -> MISHAP_RESOLVED -> #career.musteringOut (forced out)
            event                -> EVENT_RESOLVED -> commission (if military & not commissioned)
                                                    -> advancement (if military & commissioned or civilian)
            commission           -> COMMISSION_RESULT -> advancement (if not just commissioned, per CRER-12)
                                                      -> skillSelection (if just commissioned, skip advancement)
            advancement          -> ADVANCEMENT_RESULT -> skillSelection
            skillSelection       -> SKILL_SELECTED -> aging (if age >= 34)
                                                    -> continueOrLeave (if age < 34)
            aging                -> AGING_RESOLVED -> continueOrLeave
            continueOrLeave      -> CONTINUE_CAREER -> survivalRoll (next term)
                                -> CHANGE_CAREER -> #career.choosingCareer
                                -> MUSTER_OUT -> #career.musteringOut
        musteringOut            -> BENEFIT_ROLLED -> musteringOut (loop for each roll)
                                -> MUSTERING_COMPLETE -> #creation.complete
    ```

    Guards to implement:
    - isMilitary: checks current career's isMilitary flag
    - isCommissioned: checks context.isCommissioned
    - notJustCommissioned: checks !context.justCommissioned (CRER-12)
    - needsAging: checks if age >= 34 (AGNG-01)
    - canContinue: checks !forcedToLeave (CRER-13)
    - mustContinue: checks forcedToStay (CRER-14)

    Actions (assign):
    - setCareer: updates currentCareer, currentAssignment, resets careerTermCount
    - incrementTerm: increments careerTermCount and totalTermsServed
    - setCommissioned: sets isCommissioned=true, justCommissioned=true
    - clearJustCommissioned: clears justCommissioned flag
    - setForceFlags: sets forcedToLeave/forcedToStay from advancement result
