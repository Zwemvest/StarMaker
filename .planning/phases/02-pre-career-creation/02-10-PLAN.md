  <action>
    **1. Fix addSkill in src/stores/character.ts (lines 75-78):**

    Replace the blind push with a duplicate-aware implementation:
    ```typescript
    addSkill: (name, level) =>
      set((state) => {
        const existing = state.skills.find((s) => s.name === name);
        if (existing) {
          // Only upgrade if new level is higher
          if (level > existing.level) {
            existing.level = level;
          }
          // Otherwise skip — skill already owned at equal or higher level
        } else {
          state.skills.push({ name, level });
        }
      }),
    ```

    This makes addSkill idempotent: calling `addSkill("Admin", 0)` three times results in one Admin-0 entry.
