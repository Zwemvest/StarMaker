<task type="auto" tdd="true">
  <name>Task 2: Create education engine with pure resolution functions</name>
  <files>
    src/engine/education.ts,
    tests/engine/education.test.ts
  </files>
  <behavior>
    - calculateEntryDM(educationTermsUsed, characteristics, path) returns correct DM: term penalty + SOC bonus for university
    - resolveEntryRoll(diceTotal, dm, target) returns { success, total, target, dm }
    - resolveGraduation(diceTotal, dm) returns GraduationResult: 'honours' if total >= 11, 'graduated' if total >= 7, 'failed' otherwise
    - calculateEntryDM with 0 terms used and SOC 9+ for university returns +1
    - calculateEntryDM with 2 terms used returns dm including -2 penalty
    - resolveEntryRoll with total 6 and target 7 returns success: false
    - resolveEntryRoll with total 7 and target 7 returns success: true
    - resolveGraduation with total 11 returns 'honours'
    - resolveGraduation with total 7 returns 'graduated'
    - resolveGraduation with total 6 returns 'failed'
    - getAvailableUniversitySkills returns UNIVERSITY_SKILLS array
    - getAcademyBasicTraining(branch) returns correct service skills for the branch
    - canAttemptEducation(termsUsed) returns true for 0,1,2 and false for 3+
  </behavior>
  <action>
    Create src/engine/education.ts with PURE functions (no React, no state, no side effects):

    1. `calculateEntryDM(educationTermsUsed: number, characteristics: Characteristics, path: EducationPath): number`
       - Start with 0
       - Add `EDUCATION_TERM_DM * educationTermsUsed` (DM-1 per previous attempt)
       - If path.socBonus and characteristics.SOC >= 9, add +1
       - Return total DM

    2. `resolveEntryRoll(diceTotal: number, dm: number, target: number): { success: boolean; total: number; target: number; dm: number }`
       - total = diceTotal + dm
       - success = total >= target
       - Return result object

    3. `resolveGraduation(diceTotal: number, dm: number): { result: GraduationResult; total: number }`
       - total = diceTotal + dm
       - If total >= HONOURS_THRESHOLD (11): result = 'honours'
       - Else if total >= GRADUATION_TARGET (7): result = 'graduated'
       - Else: result = 'failed'
       - Return { result, total }

    4. `canAttemptEducation(educationTermsUsed: number): boolean`
       - Return educationTermsUsed < MAX_EDUCATION_TERMS

    5. `getAvailableUniversitySkills(): string[]`
       - Return UNIVERSITY_SKILLS from data

    6. `getAcademyBasicTraining(branch: AcademyBranch): string[]`
       - Return ACADEMY_SERVICE_SKILLS[branch] from data

    7. `applyGraduationBenefits(result: GraduationResult, educationType: EducationType): { eduBonus: number; skillLevelBonus: number; commissionEligible: boolean }`
       - honours: eduBonus +2 (university) or +1 (academy), skillLevelBonus +1 to both chosen skills (university) or rank bonus (academy), commissionEligible = true
       - graduated: eduBonus +1 (university) or 0 (academy), skillLevelBonus 0, commissionEligible = false (academy) -- for EDUC-10 the academy grad without honours gets auto-entry but no commission
       - failed: eduBonus 0, skillLevelBonus 0, commissionEligible = false

    Write tests FIRST (RED), then implement (GREEN). Follow pure engine function pattern from Phase 1.
  </action>
