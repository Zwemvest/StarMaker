  <action>
    1. Create shared DnD components in src/components/shared/:
       - DragPool.tsx: Wraps a list of draggable items using `useDraggable` from @dnd-kit/core. Generic component `DragPool<T>` accepting `items: T[]`, `renderItem: (item: T, isDragging: boolean) => ReactNode`, `getId: (item: T) => string`. Each item gets `useDraggable({ id })`. Pool dims (opacity-30) when `disabled` prop is true.
       - DropSlot.tsx: A droppable target slot using `useDroppable` from @dnd-kit/core. Props: `id: string`, `label: string`, `children: ReactNode`, `isEmpty: boolean`. Shows scanner-blue border highlight when `isOver`. Shows dashed border when empty.
       - DiceDisplay.tsx: Renders individual die results as styled number chips. Props: `dice: number[]`, `total: number`, `modifier?: number`. Displays each die as `[N]` chip in mono font, then `= total` (with modifier shown as `+M` or `-M` if non-zero).
       - RollLogDrawer.tsx: Collapsible bottom drawer toggled by HashBar. Props: `isOpen: boolean`, `onToggle: () => void`. Reads `rollLog` from `useCharacterStore()`. Renders entries in a scrollable list showing context, notation, results, total, success/fail. Max height 40vh, overflow-y-auto. Slide-up animation with 200ms transition.

    2. Create hooks in src/hooks/:
       - useCreationMachine.ts: Wrapper around `useActor(creationMachine)` from @xstate/react. Returns `{ state, send, currentPhase: CreationPhase }` where `currentPhase` is derived from `state.value`. Import `creationMachine` from src/machines/creation.ts. Use `createActor` + `useSelector` pattern from XState v5.
       - useLoggedRoll.ts: Atomic roll+log+hash hook. Uses `useCharacterStore` to access `appendRoll`, `rollLog`, `setLegitimacyHash`. Exposes `loggedRoll2D(context: string, modifier?: number, target?: number): Promise<RollLogEntry>` which: (a) calls `rollDice(2, 6)` to get individual dice, (b) creates entry via `createRollLogEntry()`, (c) calls `appendRoll(entry)`, (d) recomputes hash via `computeHash([...rollLog, entry])`, (e) calls `setLegitimacyHash(hash)`, (f) returns the entry. This ensures every roll is atomically logged and hashed.
       - useDragAssign.ts: Reusable drag-to-slot logic hook. Generic `useDragAssign<T>(config: { pool: T[], slotCount: number, getId: (item: T) => string })`. Returns `{ assignments: (T | null)[], assignToSlot: (item: T, slotIndex: number) => void, unassignSlot: (slotIndex: number) => void, unassignedPool: T[], isComplete: boolean, handleDragEnd: (event: DragEndEvent) => void }`. Manages state internally with useState. `handleDragEnd` parses dnd-kit's `over.id` to determine target slot index.

    Configure @dnd-kit PointerSensor with `activationConstraint: { distance: 8 }` to prevent accidental drags (per research pitfall #2). Document this in a comment in DragPool.tsx so downstream consumers know the pattern.
