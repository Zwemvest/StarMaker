From src/types/equipment.ts (created/locked in 04-01):
```typescript
export type EquipmentCategory =
  | 'weapons' | 'armour' | 'survival' | 'electronics' | 'medical' | 'tools';

interface EquipmentBase {
  name: string;
  tl: number;
  /** Cost in credits */
  cost: number;
  /** Mass in kg */
  mass: number;
  traits: string[];
}

export interface WeaponItem extends EquipmentBase {
  category: 'weapons';
  /** e.g. "Melee", "10m", "50m" */
  range: string;
  /** e.g. "3D", "2D-2" */
  damage: string;
  magazine: number | null;
  magazineCost: number | null;
}

export interface ArmourItem extends EquipmentBase {
  category: 'armour';
  protection: number;
  rad: number;
}

export interface GearItem extends EquipmentBase {
  category: 'survival' | 'electronics' | 'medical' | 'tools';
  description: string;
}

export type Equipment = WeaponItem | ArmourItem | GearItem;

export interface OwnedEquipment {
  item: Equipment;
  quantity: number;
}
```

Source material: `Sourcebooks/MgT 2E - Core Rulebook (Printer Friendly).pdf` — the
Equipment chapter. The relevant tables are:
- **Weapons**: the Melee Weapons table and the Ranged Weapons / Guns tables
  (each row gives TL, Range, Damage, Cost, Mass / kg, Magazine, Magazine Cost, Traits).
- **Armour**: the Armour table (TL, Protection, Rad, Cost, Mass, required skill/traits).
- **Survival / Electronics / Medical / Tools**: the general equipment tables in the
  Equipment chapter (each row gives TL, Cost, Mass, and a short description; group rows
  by the catalog's own section headings into the four gear categories).

Transcription rule (game-data exception to "no placeholders"): read the PDF and
transcribe the REAL values. A comment like `// p.118 Core Rulebook` next to a row is
encouraged for traceability. Do NOT invent stats. Where a table omits a field, follow
the conventions in <data_conventions> below rather than guessing.

<data_conventions>
- Every row becomes one object literal typed by its category's variant.
- `traits` is always an array. Empty trait cell → `[]`. Split multi-trait cells on
  commas into separate strings (e.g. `['Auto 3', 'AP 5']`).
- `cost` is a plain number of credits (strip the "Cr" prefix and any thousands commas:
  "Cr1500" → 1500, "Cr10,000" → 10000).
- `mass` is a number in kg. "—" / blank / negligible → 0. Fractional kg stays fractional
  (e.g. 0.25).
- WeaponItem.`range`: transcribe the table's Range cell as a string ("Melee" for melee
  weapons; metre values like "50m" for ranged). WeaponItem.`damage`: the Damage cell as
  a string ("2D", "3D-3", "4D" etc.).
- WeaponItem.`magazine` / `magazineCost`: numbers from the Magazine / Magazine Cost cells.
  Melee weapons and any weapon with no magazine → both `null`.
- ArmourItem.`protection` and `rad`: numbers from the Protection and Rad cells ("—"/blank → 0).
- GearItem.`description`: the item's one-line description from the catalog (or a faithful
  paraphrase if the row has no prose description).
- Use a consistent `as const satisfies readonly <Variant>[]` (or an explicit
  `: readonly WeaponItem[]` annotation) so TypeScript checks each literal against the type.
</data_conventions>
