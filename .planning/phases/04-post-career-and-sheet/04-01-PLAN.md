  <behavior>
    - EquipmentCategory unchanged: 'weapons' | 'armour' | 'survival' | 'electronics' | 'medical' | 'tools'
    - Equipment = WeaponItem | ArmourItem | GearItem, discriminated on `category`
    - Shared base fields on all three: name (string), tl (number), cost (number, credits), mass (number, kg), traits (string[])
    - WeaponItem: category 'weapons'; adds range (string, e.g. "Melee", "10m"), damage (string, e.g. "3D"), magazine (number | null), magazineCost (number | null)
    - ArmourItem: category 'armour'; adds protection (number), rad (number)
    - GearItem: category 'survival' | 'electronics' | 'medical' | 'tools'; adds description (string)
    - OwnedEquipment = { item: Equipment; quantity: number } — owned-item wrapper used by the store/sheet
    - Zod equipmentSchema = discriminatedUnion('category', [...]) validating each variant; equipmentSchema.parse() succeeds for a valid weapon/armour/gear object and throws for a weapon missing `damage`
  </behavior>
  <action>
    1. Replace src/types/equipment.ts entirely:
       ```typescript
       export type EquipmentCategory =
         | 'weapons' | 'armour' | 'survival' | 'electronics' | 'medical' | 'tools';

       interface EquipmentBase {
         name: string;
         tl: number;
         /** Cost in credits */
         cost: number;
         /** Mass in kg */
         mass: number;
         traits: string[];
       }

       export interface WeaponItem extends EquipmentBase {
         category: 'weapons';
         /** e.g. "Melee", "10m", "50m" */
         range: string;
         /** e.g. "3D", "2D-2" */
         damage: string;
         magazine: number | null;
         magazineCost: number | null;
       }

       export interface ArmourItem extends EquipmentBase {
         category: 'armour';
         protection: number;
         rad: number;
       }

       export interface GearItem extends EquipmentBase {
         category: 'survival' | 'electronics' | 'medical' | 'tools';
         description: string;
       }

       export type Equipment = WeaponItem | ArmourItem | GearItem;

       export interface OwnedEquipment {
         item: Equipment;
         quantity: number;
       }
       ```
    2. Create src/schemas/equipment.ts with `z.discriminatedUnion('category', [...])`:
       - weaponSchema: category z.literal('weapons') + base fields + range, damage (z.string()), magazine z.number().nullable(), magazineCost z.number().nullable()
       - armourSchema: category z.literal('armour') + base + protection z.number(), rad z.number()
       - gearSchema: category z.enum(['survival','electronics','medical','tools']) + base + description z.string()
       - export const equipmentSchema = z.discriminatedUnion('category', [weaponSchema, armourSchema, gearSchema]); export const equipmentCatalogSchema = z.array(equipmentSchema);
       Note: z.discriminatedUnion requires the discriminator to be a literal in each member. gearSchema uses z.enum on category which discriminatedUnion does not accept as a single discriminant across 4 values — instead create FOUR gear members (one z.literal per gear category) OR model gear as a separate union and combine with z.union. Use z.union([weaponSchema, armourSchema, gearSchema]) with gearSchema's category as z.enum to keep it simple, and add a .refine if needed. Prefer z.union here for correctness.
  </action>

  </verify>
