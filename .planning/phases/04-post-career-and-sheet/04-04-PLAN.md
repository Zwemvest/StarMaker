<objective>
Extend the Zustand character store and the XState creation machine to support the
Phase 4 post-career sequence, and close the legitimate-psionics wiring gap.

Purpose:
- The store must carry the psionics result (unlock flag, PSI strength, acquired
  talents) and owned equipment, plus a credit-spend action — all persisted and
  reset-aware, per the LOCKED 04-01 contract.
- The machine must add the three post-career workflow positions (`psionics`,
  `equipment`, `sheet`) and the events that thread them after mustering out.
- The legitimate psionics door (D-2) must actually open: when a Life Events roll
  12 resolves its Unusual 1D sub-table to result `1`, the store's
  `psionicsUnlocked` is set true WITHOUT flipping the character to Modified.

Output: extended `src/stores/character.ts`, extended `src/machines/creation.ts`,
the Unusual-Event wiring in the career event resolution component, and tests for
all three.

This plan is flow plumbing only. No psionics/equipment UI (that is 04-05), no
sheet rendering (04-06). The `psionics` state is ALWAYS entered; its UI later
decides whether to show the test or auto-advance. Per the project's strict
XState/Zustand separation, the machine holds workflow position ONLY — all
character data (unlock flag, PSI strength, talents, equipment, credits) lives in
the store.
</objective>
