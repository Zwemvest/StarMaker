  <action>
Design the roll log format and type system FIRST (per research recommendation — everything downstream depends on this).

**src/types/common.ts:**
- `CharacteristicId` = `'STR' | 'DEX' | 'END' | 'INT' | 'EDU' | 'SOC'`
- `Modifier` lookup function type (characteristic value -> DM)
- `SkillLevel` = number (0-4 during creation)

**src/types/dice.ts:**
- `DiceNotation` = `'1D' | '2D' | '3D' | 'D3' | 'D66'`
- `RollResult` = `{ notation: DiceNotation; dice: number[]; total: number }`
- `RollLogEntry` = `{ id: string; context: string; notation: DiceNotation; results: number[]; total: number; modifier: number; target: number | null; success: boolean | null; overridden: boolean }`
  - `id`: UUID v4
  - `context`: dot-path like `"characteristics.STR"`, `"career.marines.survival"`
  - `results`: individual die values
  - `total`: sum of results + modifier
  - `overridden`: false by default, true if override mode was used

**src/types/character.ts:**
- `Characteristics` = `Record<CharacteristicId, number>`
- `Skill` = `{ name: string; level: number }`
- `CharacterInfo` = `{ name: string; age: number; title: string | null; credits: number; pension: number }`
- `Contact` = `{ type: 'contact' | 'ally' | 'rival' | 'enemy'; name: string; notes: string }`
- `Character` = full character type with: `id`, `info`, `characteristics`, `skills`, `careers` (career history), `contacts`, `rollLog` (RollLogEntry[]), `legitimacyHash`, `isModified`, `createdAt`

**src/types/careers.ts:**
- `CareerName` = union of all 12 career names: `'agent' | 'army' | 'citizen' | 'drifter' | 'entertainer' | 'marine' | 'merchant' | 'navy' | 'noble' | 'rogue' | 'scholar' | 'scout'`
- `Assignment` = `{ career: CareerName; name: string; description: string }`
- `Rank` = `{ level: number; title: string; bonusSkill: string | null }`
- `CareerTerm` = `{ career: CareerName; assignment: string; term: number; rank: number; skills: Skill[]; events: string[] }`
- `CareerHistory` = `CareerTerm[]`

**src/types/equipment.ts** (stubs for Phase 1):
- `EquipmentCategory` = `'weapons' | 'armour' | 'survival' | 'electronics' | 'medical' | 'tools'`
- `Equipment` = `{ name: string; category: EquipmentCategory; cost: number; tl: number; traits: string[] }`

**src/schemas/roll-log.ts:**
- Define `rollLogEntrySchema` using Zod 4 that validates `RollLogEntry`
- Export both schema and inferred type
- Ensure the schema enforces: id is UUID-like string, context is non-empty string, notation is one of the valid values, results is array of positive integers, total is integer

**src/schemas/character.ts:**
- Define `characteristicsSchema` validating all 6 stats as integers 0-15
- Define `characterSchema` for the full character type
- Export schemas and inferred types

IMPORTANT: Types in `src/types/` are the canonical definitions. Zod schemas in `src/schemas/` should validate runtime data against those shapes. Align them but types are primary (Zod schemas may not cover every type — that's fine for Phase 1).
